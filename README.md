# Development Workflow Platform

A closed-loop development lifecycle platform built entirely by AI agents from a hand-drawn architecture doodle using [claude-ai-OS](https://github.com/Jason-CullumICT/claude-ai-OS).

## What It Does

Manages the full feature development lifecycle: intake, AI triage, human approval, prioritized development cycles with pipeline orchestration, and automated documentation.

**7 subsystems:**
- **Feature Requests** — submit from multiple sources (manual, Zendesk, competitor analysis, code review)
- **AI Voting & Triage** — 5 AI agents vote on each feature with comments
- **Human Approval** — voting is advisory; humans make the final call
- **Bug Tracking** — severity/priority classification, bugs-before-features priority
- **Development Cycles** — 6-phase linear progression with ticket kanban board
- **Pipeline Orchestration** — 5-stage automated pipeline auto-advances cycle phases
- **Learnings & Features** — documentation and feature catalog from completed cycles

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Express + TypeScript + SQLite (better-sqlite3) |
| Frontend | React 18 + Vite + TypeScript + Tailwind CSS |
| Routing | React Router 6 |
| Testing | Vitest + React Testing Library + Supertest |
| Observability | Prometheus metrics + OpenTelemetry tracing + structured JSON logging |
| Shared Types | Single source of truth in `Source/Shared/` |

## Quick Start

```bash
# Backend
cd Source/Backend
npm install
npx ts-node src/index.ts
# → http://localhost:3001

# Frontend (new terminal)
cd Source/Frontend
npm install
npx vite --host --port 5173
# → http://localhost:5173
```

Login not required — v1 has no auth (deliberate scope decision).

## How It Was Built

This entire codebase was generated by the [claude-ai-OS](https://github.com/Jason-CullumICT/claude-ai-OS) multi-stage AI pipeline:

1. **Input**: A hand-drawn doodle of the architecture
2. **Planning**: Team leader analyzed the image, wrote specifications and API contracts
3. **Implementation**: Backend and frontend coders built in parallel
4. **QA**: Security, traceability, design, integration, and chaos agents reviewed independently
5. **Validation**: Automated smoketests + Inspector audit

8 pipeline runs, 69 FRs, 24 design decisions, 542 tests — all automated.
